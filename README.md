 # Дисциплина "Основы алгоритмизации и программирования"
Репозиторий предназначен для хранения всех материалов, связанных с дисциплиной.

## Описание дисциплины
Изучение данной дисциплины направлено на изучение различных алгоритмов: в течение курса предстоит научиться распознавать алгоритмы, объяснять принцип их работы и применять их на практике.

## Навигация по работам

| **lesson_02** | hw-02 | Второе ДЗ по дисциплине: сложность и O-нотация. |
| **lesson_03** | hw-03 | Третье ДЗ по дисциплине:  замеры времени и памяти. |
