Алгоритмы: 
1. Рекомендации Ютуба. 
	Вход: история просмотров + подписки на каналы. 
	Правила: делает выборку из наиболее часто встречающихся тем за последнее время, отбирает наиболее похожие по темам, авторам видео за какой-то промежуток времени, иногда - группирует по автоматически сгенерированным плейлистам (в основном так поступает с песнями). 
	(на самом деле никто не знает, как работают алгоритмы ютуба...) 
	Выход: подборка рекомендуемых видео на главной странице. 

2. Прогноз погоды на телефоне. 
	Вход: геоданные телефона. 
	Правила: телефон отправляет координаты геопозиции на метеорологический сервер в интернете, получает соответствующий им пакет данных о погоде и распаковывает их. 
	Выход: в приложении погоды отображается соответствующий прогноз. 

3. Подсказки слов на телефоне. 
	Вход: набор пользовательского текста. 
	Правила: система сравнивает вводимую комбинацию букв в тексте с БД слов языка. Если ввод совпадает с началом слова из базы, она отбирает самые часто используемые варианты. 
	Выход: всплывающая подсказка над клавиатурой с 3 вариантами слов для дополнения. 


Если данных станет больше - на примере рекомендаций ютуба: 
	Вход: данных стало в миллион раз больше.	 	 
	Итог:  
	1. Поиск по схожим тегам и авторам затруднится, т.к при увеличении входных данных увеличится количество схождений тегов между видео -> рекомендации рискуют превратиться в кашу из совершенно разных видео, где теги сошлись по одному совпадению. 
	2. Увеличится время вычисления и нагрузка на сервер -> сравнений между просмотренными и потенциально рекомендуемыми видео станет слишком много для их просчёта за адекватное количество времени. 

 

Определения: 
1. Алгоритм - способ за конечное количество действий прийти к определённому результату при обозначенных входных данных. 
2. Инвариант - определённое свойство или утверждение, которое должно оставаться верным на каждом этапе алгоритма/цикла, чтобы доказать, что алгоритм/цикл выполняет корректную работу.
